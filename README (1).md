# Portofolio – Juliotama Stefanus Sitepu

Website portofolio pribadi milik **Juliotama Stefanus Sitepu**, mahasiswa Ilmu Komputer Universitas Negeri Medan (UNIMED). Dibangun dengan HTML5 dan CSS murni tanpa framework atau JavaScript.

## Fitur

- **Tentang Saya** – perkenalan singkat, minat pada teknologi, musik, dan hobi lainnya
- **Biodata** – data diri lengkap dalam bentuk tabel
- **Keahlian** – Musik, Gaming, dan Editor, lengkap dengan indikator tingkat kemahiran (`<progress>`)
- **Pendidikan** – riwayat pendidikan dari SD sampai S1 dalam tampilan garis waktu
- **Kontak** – formulir kirim pesan dan tautan Instagram, Email, serta WhatsApp
- Tampilan bertema gelap dengan aksen kuning dan toska, responsif untuk layar HP, dan mendukung `prefers-reduced-motion`

## Struktur Proyek

```
.
├── index.html            # Halaman utama
├── style.css             # Seluruh gaya tampilan
├── 1000248714 (1).jpg    # Foto profil
└── README.md             # Dokumentasi ini
```

## Cara Menjalankan

1. Unduh atau clone repositori ini.
2. Pastikan `index.html`, `style.css`, dan file foto berada dalam satu folder.
3. Buka `index.html` di browser (klik dua kali, atau gunakan ekstensi seperti *Live Server* di VS Code).

Tidak diperlukan instalasi atau proses build.

## Teknologi

- HTML5 (semantik: `header`, `nav`, `main`, `section`, `footer`, `table`, `form`)
- CSS3 (custom properties, grid, flexbox, media query)
- Google Fonts: Bebas Neue, Space Grotesk, JetBrains Mono (membutuhkan koneksi internet)

## Catatan

- Formulir kontak saat ini belum terhubung ke server (`action="#"`), sehingga pesan belum benar-benar terkirim. Untuk mengaktifkannya, gunakan layanan seperti Formspree atau backend sendiri.
- Nama file foto mengandung spasi dan tanda kurung. Disarankan menggantinya, misalnya `foto-profil.jpg`, lalu perbarui atribut `src` di `index.html`.
